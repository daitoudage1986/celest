# 世界杯第2比赛日连场分析案例（2026-06-14/15）

覆盖4场比赛：德国vs库拉索、荷兰vs日本、科特迪瓦vs厄瓜多尔、瑞典vs突尼斯

## 核心方法论总结

### 1. 数据更新分析流程

当用户要求"根据数据变化更新"某场比赛时，按以下顺序更新：

1. **重新抓取titan007分析页** → 检查天气变化、伤病更新、数据更新时间戳
2. **重新抓取亚指页面** → 对比上次与本次的盘口、贴水变化
3. **重新搜索赔率** → 对比早盘与即时赔率变化
4. **更新Poisson模型** → 将天气/伤病变化作为系数调整重新跑计算
5. **重新输出完整报告** → 标注"数据变化总览"表格、旧值vs新值对比

### 2. 亚指数据提取方法（titan007 AsianOdds_n.aspx）

提取流程：
- 用 `mcp_lightpanda_goto` 导航到 `https://vip.titan007.com/AsianOdds_n.aspx?id={match_id}&l=0`
- 用 `mcp_lightpanda_evaluate` 执行 `document.body.innerText.substring(offset_start, offset_end)`
- 从文本中解析出每行的时间、盘口名、两队贴水
- 时间格式如 `6-14 13:10`，盘口如 `三球半`，贴水如 `0.98`

关键识别词汇：
- 平手 = 0.0 (PK)
- 平手/半球 = 0.0/0.25
- 半球 = 0.5
- 半球/一球 = 0.5/0.75
- 一球 = 1.0
- 一球/球半 = 1.0/1.25
- 球半 = 1.5
- 球半/两球 = 1.5/1.75
- 两球 = 2.0
- 受让 = receiving the handicap (前缀)
- 三球半 = 3.5
- 三球/三球半 = 3.0/3.5

### 3. 线位分析报告写法

亚指分析段落的标准结构：
```
📐 亚指线位分析（[盘口名]）：
  盘口: 始终/变到了[盘口名]（[时间范围]）
  [A队]贴水: [范围]（从[开盘值]到[当前值]⬇️/⬆️[趋势]）
  [B队]贴水: [范围]（从[开盘值]到[当前值]⬇️/⬆️[趋势]）
  试盘([日期]): 曾短暂[某盘口]后立即回落→市场拒绝接受该方向
  最新: [A队贴水] vs [B队贴水] → [资金方向结论]
```

### 4. 天气变化处理

| 天气变化 | 调整系数 | 适用场景 |
|---------|---------|---------|
| 雨→晴 | x1.03-1.05 | 技术型球队受益更大 |
| 晴→雨 | x0.92-0.95 | 总进球下降，偶然性增加 |
| 高温(>30°C) | x0.92-0.95 | 对技术型和体能劣势方影响更大 |
| 无变化 | x1.00 | — |

### 5. 伤病调整系数

| 伤病类型 | 调整系数 | 示例 |
|---------|---------|------|
| 主力门将缺阵 | 防守-8%~-12% | 荷兰Verbruggen缺阵 |
| 主力中卫缺阵 | 防守-5%~-10% | 科特迪瓦Ndicka疑似 |
| 核心攻击手缺阵 | 进攻-10%~-15% | 内马尔缺阵(巴西1-1摩洛哥) |

调整方法：在Poisson计算的攻防强度阶段应用
```python
adjusted_def = raw_def * (1 + injury_adjust)
# 或 adjusted_att = raw_att * (1 + injury_adjust)
```
