当标准数据源（The Odds API + football-data.org）不覆盖目标联赛时，使用此方法。

### 欧指获取替代方案（当 titan007 不可用时）

当 `1x2.titan007.com` 页面无法加载欧指数据（这是常态），使用搜索引擎获取：

```python
# 步骤1：搜索比赛赔率
mcp_anysearch_search(query="Mexico vs South Africa odds 1X2 betting", freshness="week")

# 步骤2：从搜索结果摘要中提取
# 常见摘要格式：
# - Oddspedia: "Mexico -238, Draw +350, South Africa +800" → 1.42/4.50/9.00
# - Kalshi: "Mexico 69%, Draw 21%, SA 11%" → 1.45/4.76/9.09
# - DraftKings: "Mexico -247 TOTAL 2.5" → 隐含 1.40

# 步骤3：美式赔率转十进制
# 正数(+)：odds = 1 + (american/100)   例：+350 → 4.50
# 负数(-)：odds = 1 + (100/abs(american))  例：-238 → 1.42
```

### 分析页数据提取要点（通过 LightPanda）

分析页 `zq.titan007.com/analysis/{id}sb.htm` 提供以下关键数据段落：

## 工作流程

### Step 1 — 打开赔率页面

```
https://op1.titan007.com/oddslist/{match_id}.htm
```

match_id 从球探体育的赛事 ID 获取。

### Step 2 — 提取最佳赔率

用浏览器 console 执行以下脚本提取百家欧指最佳赔率：

```javascript
(function() {
  const rows = document.querySelectorAll('table > tbody > tr');
  let best = { home: 0, draw: 0, away: 0 };
  rows.forEach(row => {
    const cells = row.querySelectorAll('td');
    if (cells.length < 13) return;
    const home = parseFloat(cells[2]?.innerText);
    const draw = parseFloat(cells[3]?.innerText);
    const away = parseFloat(cells[4]?.innerText);
    if (home && draw && away) {
      best.home = Math.max(best.home, home);
      best.draw = Math.max(best.draw, draw);
      best.away = Math.max(best.away, away);
    }
  });
  return best;
})();
```

输出格式：`{ home: 2.75, draw: 3.10, away: 3.15 }`

**注意事项：**
- 页面有 90-100 家博彩公司，最佳赔率通常出现在中小型博彩公司
- 90家×3个选项 → 大量数据点，平均值也很有参考价值
- 平均赔率 = sum(所有公司赔率) / 公司数量

### Step 3 — 获取球队历史数据

点击页面 **"分析" tab** (ref=e9)，获取积分排名表。

从表中提取两队的主/客场数据：

```
| 球队 | 总场 | 胜 | 平 | 负 | 进 | 失 | 净 | 积分 | 排名 |
| 主队: 总/主/客/近6 四行数据
```

提取关键指标：
- **主队主场数据**：主场场次、进球、失球
- **客队客场数据**：客场场次、进球、失球
- **近6场数据**：近6场战绩（用于近期状态）

### Step 4 — 计算攻防强度

```python
# 联赛场均进球参数（估算）
# 南美: 主场 ~1.45-1.50, 客场 ~1.10-1.15
# 亚洲: 主场 ~1.50-1.55, 客场 ~1.15-1.18
# 北欧: 主场 ~1.55-1.60, 客场 ~1.20-1.22

league_avg_home = 1.45  # 按联赛调整
league_avg_away = 1.10  # 按联赛调整

home_att = (team_home_gf / team_home_games) / league_avg_home
home_def = (team_home_ga / team_home_games) / league_avg_home
away_att = (team_away_gf / team_away_games) / league_avg_away
away_def = (team_away_ga / team_away_games) / league_avg_away
```

**主队：** 使用积分表中的主场数据
**客队：** 使用积分表中的客场数据

### Step 5 — 泊松预测

使用 skill 中的 `scripts/poisson_predict.py` 中的公式手动计算，或直接跑 Python 代码。

### Step 6 — 对比赔率，找价值

```
edge = model_prob * best_odds - 1
```

如果 edge > 3%（保守），视为价值投注。

## 亚指（Asian Handicap）分析

亚指（让球盘）是继百家欧指之后的**第二个独立市场信号**。欧指反映胜平负概率，亚指反映市场资金流向和盘口博弈。

### 数据来源

亚指页面: https://vip.titan007.com/AsianOdds_n.aspx?id={match_id}

### 关键分析维度

#### 1. 盘口变化方向

| 信号 | 含义 |
|------|------|
| 升盘（初盘平手→即时平手/半球） | 市场资金涌向主队，博彩公司被迫抬高门槛 |
| 降盘（初盘平手/半球→即时平手） | 资金流向客队或主队不被看好 |
| 不变 | 市场看法分歧不大或公司稳健 |

**量化指标：** 统计升盘家数 vs 降盘家数。当升盘家数远大于降盘家数（如 10:0），是极强的单边信号。

#### 2. 贴水（水位）变化

| 变化 | 含义 |
|------|------|
| 主队贴水从 0.96 → 0.80 | 公司持续下调主队赔付 → 主队利好 |
| 主队贴水 > 1.00 且持续上升 | 主队不被看好或公司规避风险 |

#### 3. 初盘 vs 即时的对比模式

| 模式 | 解读 | 可靠性 |
|------|------|--------|
| 平手 → 平手/半球 | 升盘 + 主队贴水下降 | 🟢 强信号 |
| 平手 → 平手（贴水下降） | 水位示好但盘口不变 | 🟡 弱信号 |
| 平手/半球 → 平手 | 降盘 + 客队贴水下降 | 🔴 强烈警示主队 |
| 平手/半球维持不变 | 坚定看好主队 | 🟢 稳定信号 |

#### 4. 汇总统计

亚指页面顶部会显示：
升盘: X家  降盘: Y家  高水: A家  低水: B家

**判断规则：**
- 升盘 Y - 降盘 X > 3 → 市场强烈看好方向
- 高水 A - 低水 B 显著 → 水位分歧大

### 与欧指、模型的结合使用

亚指信号不能单独使用，必须与模型和市场三重交叉验证。

| 信号 | 主队好 | 客队好 | 分歧 |
|------|--------|--------|------|
| 模型 | 主队概率>50% | 客队概率>市场35% | 模型偏离 |
| 欧指 | 主胜赔率下降 | 客胜赔率下降 | 无一致方向 |
| 亚指 | 升盘+贴水降 | 降盘+客贴降 | 盘口稳定/波动 |

### 实战案例

**2026-05-29 辽宁铁人 vs 上海海港（中超）：**
- 初盘：6家公司开平手0.75-0.85水，澳*开平手/半球0.96水
- 即时：10家升盘至平手/半球（0家降盘），亚指升盘统计 10 🟢 / 0 🔴
- 贴水：辽宁从0.77-0.85区间→平手/半球0.76-0.84区间
- 解读：市场资金一边倒涌向主队，信号极强 → 配合模型主胜52%（+19.6% EV），三信号一致

### 跨比赛信号对比（相对置信度校准）

当同时分析多场比赛（如同日多场友谊赛），自然会产生**相对信号强度比较**——单纯的升/降盘家数绝对值需要放在同一时段的比赛集群中比较，才能校准置信度。

**实践规则**（源自2026-05-30 友谊赛分析对比）：

| 信号强弱 | 升/降盘家数 | 实例 | 置信度 |
|:------:|:-----------|:----|:------|
| 🔴 极强 | 7-10家一致方向（单边） | 墨西哥-9降0升 | 🟢🟢🟢 可做主推 |
| 🟡 中性 | 3-5家一致 | — | 🟢🟢 中等 |
| ⚪ 微弱 | 1-2家（或持平） | 韩国1升2降 | 🟡 仅作佐证，不做主推 |

**操作方法：** 分析完当日所有比赛后，将各场的升/降盘信号强度做一次横向比较。最一致的单边信号获得最高优先级的推荐信心，模糊的比赛自然排到次要位置。孤立看一场的升/降盘数可能误判信号强弱。

### 亚指信号 vs 历史数据冲突处理

当亚指方向与历史同盘数据冲突时，按以下优先级裁决：

| 优先级 | 信号 | 可靠性基准 | 实例 |
|:---:|:-----|:----------|:----|
| 1️⃣ | 一致且剧烈 | 极高（全市场共识） | 9降0升 → 即使历史数据支持反方向 |
| 2️⃣ | 中性市场 + 历史数据 | 中（取决于样本量） | 1升2降 + 历史57.8%赢盘率 |
| 3️⃣ | 历史数据 | 低（尤其小样本） | 仅几场历史记录 |

**冲突实例（2026-05-30 墨西哥 vs 澳大利亚）：**
- 亚指信号：9降0升，强烈看衰墨西哥
- 历史数据：墨西哥-0.75盘口57.8%赢盘率，近6场5胜1输
- 裁决：信任市场信号（9降0升）> 历史数据（57.8%）
- 逻辑：历史数据可能包含通胀（墨西哥近期连胜过热），而9家同时降盘是博彩公司的真实反应——初盘定在-1说明庄家本来看好墨西哥，降到-0.75说明大资金不认同这个判断

**规则摘要：**
- 7+家一致方向 → 压倒性信号，压倒历史数据
- 3-5家一致方向 → 适度参考，结合历史数据综合判断
- 1-2家或持平 → 亚指无有效信号，依赖模型和历史数据
- 历史数据超20场时权重上调（大样本>小样本）

### 已知陷阱

- 亚指变化可能滞后于欧指变化，特别是小众联赛
- 中超等亚洲联赛的亚指灵敏度高于欧洲二级联赛
- 临场2小时的剧烈贴水变化可能是大额资金入场，应关注但不盲从
- 澳门盘口通常是风向标：澳*若开出独特盘型（与其他公司不一致），往往代表内幕信息

## 关键标记

- ⚠️ 杯赛单场淘汰制的偶然性比联赛高，模型应保守使用
- 球探体育的数据是中文球队名，注意和英文名做映射（尤其非主流联赛）
- 球探页面有会员专区（球队实力对比分析），部分数据需付费解锁
- 🌡️ 天气是外部因子：高温（>30°C）通常降低进球数，尤其对客场队不利
- 伤停信息：球员缺阵（尤其是核心组织者）应在泊松期望值中进行手动修正（约-10%~-15%攻击力）

## 已知失败的案例（实盘验证）

### 2026-05-27: 奇科(茨高) 0-1 拉尼罗斯（哥伦杯）

**预测：** 强烈推荐主胜 @2.75，模型概率67.3%
**结果：** 客胜 ❌

**模型当时做了什么：**
- 从积表提取奇科主场9场5胜1平3负·进13失5 → 防守强度0.383（极强）
- 拉尼罗斯客场10场3胜3平4负·进7失11 → 进攻强度0.636（偏弱）
- 期望进球：奇科1.444 vs 拉尼罗斯0.268 → 主胜67.3%

**为什么错了：**
1. **杯赛≠联赛**：用联赛主场数据预测杯赛——拉尼罗斯19场仅输5场(10平)，杯赛体质球队
2. **小样本极端估值**：奇科9场的主场防守0.383是严重失真（无 Bayesian shrinkage）
3. **拉尼罗斯客场被低估**：客场3胜3平4负、中游排名第9，绝不是0.268期望进球的水平

**修正 → SKILL.md v2 中的 Bayesian shrinkage + 杯赛检测**

### 2026-05-27: 水晶宫 1-0 巴列卡诺（欧会杯）

**预测：** 强烈推荐客胜 @5.60，模型概率43.7%
**结果：** 主胜 ❌

**模型当时做了什么：**
- 从 football-data.org 获取两队近10场数据
- 水晶宫英超第15（近10场3胜3平4负）
- 巴列卡诺西甲第8（近10场6胜3平1负）
- 期望进球（近期加权）：水晶宫0.82 vs 巴列卡诺1.51
- 结论：巴列卡诺43.7% > 市场隐含26.5%，巨大价值

**为什么错了：**
1. **中立场被当主场**：莱比锡中立场，但模型用英超主场均值1.53算水晶宫期望
2. **跨联赛对比缺陷**：英超第15 ≠ 弱于西甲第8，英超整体强度更高
3. **近期状态过度权重**：巴列卡诺6胜是在西甲末段对手无欲无求的情况下
4. **无视市场信号**：赔率1.88/3.00/3.78 + 亚让-1 明确指向水晶宫，模型无视了

**修正 → SKILL.md v2 中的中立场检测、双轨加权、市场背离预警**
